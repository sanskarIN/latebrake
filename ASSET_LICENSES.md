# Game asset provenance

This file tracks every game asset to which Latebrake has distribution rights.

| Asset | Origin | Included in repository? | Rights/notes |
| --- | --- | --- | --- |
| Temporary car body/wheels/cabin | UE 5.8 built-in `/Engine/BasicShapes` meshes | No | Engine-owned reference; governed by Epic's terms |
| Temporary circuit/ground/barriers | Runtime instances of UE 5.8 built-in primitive meshes | No | Engine-owned reference; governed by Epic's terms |
| Race markers | Runtime instances of UE 5.8 built-in cylinder | No | Engine-owned reference; governed by Epic's terms |

No original production car models, environment packs, music, textures, vehicle brand logos, title graphics, fonts, or other imported production assets are currently included.

For each future asset record: exact path, creator, source URL, permission/license, proof/attribution location, editing history, date checked, and distribution restrictions. Do not add non-redistributable Marketplace content to the public Git repository.
