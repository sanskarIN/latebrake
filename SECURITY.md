# Security policy

Latebrake is early-development game software. **No stable release is supported yet.**

## Report privately

Please do not publicly disclose a potentially exploitable vulnerability before maintainers have an opportunity to investigate.

Report to either:

- sanskarprogrammer@gmail.com
- sanskarcodes@outlook.com

Include affected commit/version, platform, reproducible steps, expected/actual behavior and impact. Omit personal data and credentials. Maintainers will attempt to triage and provide a fix path; no response-time guarantee is currently made.

## Security expectations

Keep saves local and avoid logging sensitive data. Future multiplayer must validate results on an authoritative server and never trust unverified client submissions. Avoid adding analytics, telemetry or third-party SDKs without privacy/legal review. Check license and supply-chain impact of each dependency.
