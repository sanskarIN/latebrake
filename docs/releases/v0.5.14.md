# LateBrake v0.5.14 — Candidate Packaging Integrity

**SOURCE-ONLY GitHub pre-release. This is NOT a playable game build.**
**No compiled Win64 EXE, Android APK/AAB, or installed game is included.**
GitHub source ZIP/tar.gz links contain project source and tests, **not installers**.

## Source work since the previous v0.5.8 preview

- **v0.5.9/v0.5.10 — safer race clock:** portable C++20 gate policies require a ready circuit, valid local player pawn and an unpaused, unfinished racing session before scoring checkpoints or advancing elapsed time.
- **v0.5.11 — pause-resume checkpoint isolation:** portable `CheckpointSessionTrace` rejects a checkpoint crossing inferred across paused time, including when actor ticks did not run during pause. Integrates with actual four-gate `RaceProgress` policy.
- **v0.5.12 — filesystem candidate integrity:** prevent malicious or accidental symlink/junction traversal through parent directories, and reject inconsistent/empty package inputs.
- **v0.5.13 — QA bound to exact cooked candidate:** an installed-game report must include `candidate_manifest_sha256`, not just the source commit, so another UAT build of identical source cannot inherit stale QA.
- **v0.5.14 — reject malformed package structures:** post-UAT preflight rejects undersized/incorrect Windows executable signatures, insufficient cooked .pak/.ucas, malformed Android APK ZIP or missing native/DEX/AndroidManifest.xml. Negative-only portable fixtures validate rejection paths.
- Updated README, build/QA instructions, engineering status, roadmap, and Windows/Linux/macOS C++20 portable regression tests.

## Source-only release verification

A dedicated release workflow builds/tests the actual portable C++20 source on **Ubuntu, Windows, and macOS**, runs Windows PowerShell package-policy negatives and editor-only Python syntax/stub tests on the exact source commit, then tags that immutable commit and publishes this GitHub **pre-release with zero executable attachments**.

**This is NOT a playable game build.** Real Unreal Engine 5.8/UHT/editor compilation, authentic binary project map, genuine Win64 or Android Cook/BuildCookRun success, and physical installed driving tests remain **UNVERIFIED**. Structural file checks do not prove that an EXE/APK launches or renders a race.

## Qualification needed before any playable release

1. Compile a properly licensed Unreal Engine 5.8 Editor and the LateBrake game module; create/cook the genuine `/Game/Maps/LatebrakeCircuit`.
2. Package Win64/Android with the authorized real SDK and engine. Record exact candidate manifest SHA256 and full logs.
3. Install and drive on actual supported devices; check gates, lap finish, touch pause/orientation, save/load, collision, rivals and frame time.
4. Record results in [checkpoint validation #31](https://github.com/sanskarIN/latebrake/issues/31) and [Android touch validation #13](https://github.com/sanskarIN/latebrake/issues/13).
