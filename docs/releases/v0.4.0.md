# Latebrake v0.4.0 — Circuit & Environment (Source Pre-release)

**Type: SOURCE-ONLY GitHub pre-release. Not a verified playable game.**

## Added
- Shared track geometry so the player, ordered gate actors and the experimental AI rival all use identical course waypoints and safe recovery poses.
- Engine-primitive, non-colliding painted lane stripes, alternating red/white curbs, spectator-stand tiers and start/finish banner on the existing starter circuit.
- Responsive desktop north-up minimap showing the active circuit, player position and next checkpoint.
- Portable C++20 geometry, decoration and minimap projection tests, covering invalid indexes and nonfinite values.

## Verified boundaries

The prerelease workflow must run the existing and new C++20 CMake/CTest suites on Windows, Ubuntu and macOS against the exact published source revision. **No Unreal 5.8 editor/UHT compilation, in-game visual inspection, real racing physics check, package cooking or physical Win64/Android gameplay tests have been performed.**

This is still **one original starter layout**, not a claimed multi-track racing game. Added ornaments use individual actor meshes; potential draw-call overhead, colors, lighting and collision must be measured.

## Missing for stable 1.0

Actual Unreal build, authored cooked level and polished vehicle/environment assets, a reliable installer/APK, graphics/physics optimization, user-facing menus and game-device QA. See [issue #2](https://github.com/sanskarIN/latebrake/issues/2), [track design](../TRACK.md) and [test plan](../TESTING.md).

Only GitHub source archives are published. No empty/fake executable attachments. Authored source BSD-3-Clause; Epic engine content has separate terms.
