# LateBrake v0.5.72 — Four Camera Views and Android CAM

**SOURCE-ONLY GitHub pre-release. This is NOT a playable game build.**
**No compiled Win64 EXE, Android APK/AAB, or installed game is included.**
The GitHub source archives are **not installers**; this pre-release has
**zero executable binaries**. Unreal Engine 5.8/UHT, an original cooked
map, actual game packaging, real physics/camera/touch QA and stable
release acceptance are **not complete**.

## New source features over independently qualified v0.5.71

- A real four-state camera cycle replaces the old near/far toggle:
  **CHASE → CLOSE CHASE → HOOD → HIGH CHASE → CHASE**.
  Each preset configures the Unreal spring arm's distance, pitch,
  forward and vertical socket position, camera lag and collision
  probe consistently. Unsupported/unsafe values use safe fallback.
- Keyboard/gamepad C input retains its existing binding.
  Spacious racing HUD layouts display the chosen view after official
  lap and clock readouts, never claiming camera settings are race data.
- On Android the reserved upper-middle `MenuBrowse` rectangle is
  newly drawn as **CAM during a race**. It remains BROWSE in menus.
  Discrete camera changes require an actual fresh pressed finger on
  that pad, qualified circuit/local driver, and no menu, pause or
  focus-loss latch. Steering, GAS, BRAKE, PAUSE, RESTART and RECOVER
  screen rectangles are not relocated; drags into CAM do not trigger it.
- New production-referenced Unreal source-binding tests and strict
  C++20 `CameraPresets` / `TouchCameraCyclePolicy` tests cover
  cycle, fallback, bounded geometry, touch hit regions, pause/focus,
  press-only gating and HUD priority.

## Independent release requirements

The source publisher checks out one exact `main` Git SHA on Ubuntu,
Windows and macOS, compiles and runs the full strict C++20 portable
suite (plus explicit camera and touch regressions), runs all Python
editor-source binding checks, PowerShell syntax and synthetic release
candidate rejection policies, and renders/verifies GitHub Pages docs.
It rejects moved main, mismatched existing tags, runnable attached
assets, missing source warnings and an unqualified previous v0.5.71
source-only release.

## Mandatory unfinished real-engine and package work

Licensed UE 5.8 Editor/UHT and Game compilation, original cookable
circuit `.umap`, actual car chase/cockpit mesh clipping, camera shake/
spring-arm collision handling, Win64 executable, Android APK/AAB,
multi-finger device gameplay, frame-time and save/restart QA must be
performed on real engine and devices before a **playable** release.
See [Camera QA](https://github.com/sanskarIN/latebrake/blob/main/docs/CAMERA_PRESETS_QA.md)
and [Android qualification](https://github.com/sanskarIN/latebrake/issues/13).
