## 3D track work since v0.5.95

- Add an original **1.70265-km world-scale rounded track** profile with
  80-m-radius bends and **9-m physical road width**, while retaining a
  separately tested 170-m original prototype. Never enlarge the vehicle,
  steering or road width by the 10x longitudinal world scale.
- Specify and numerically validate **68 collision-backed slab transforms**
  for an independent editor-only prototype, including original z=-1 cm
  physical surface and a distinct original 8.5-m-wide 3D visual ribbon.
- Export original continuous **4,096-vertex / 8,192-triangle** OBJ+MTL
  visual track models with lap-wrapped UV and independent Python/C++
  integrity verification. These material placeholders are **not
  photorealistic original assets**, shader graphs or collision meshes.
- Add an isolated `-WorldScale` Unreal Editor **lab-authoring source
  workflow**, with a separate lab map, original compiled C++ numeric
  JSON contract, source-byte SHA256 handoff, 68 BlockAll actor readbacks,
  physical width and heading checks and genuine Editor map save/reload
  verification requirements. This source workflow has NOT been exercised
  in an actual licensed Unreal Editor.
- Specify a new **continuous 9-m-wide physical road collision-surface
  geometry candidate**, top z=-1 cm and bottom z=-43 cm, with 1,024
  centreline cross-sections, closed 4,096-vertex / 8,192-face topology,
  smooth curvature/UV-independent physical vertices and a strict
  `WorldScaleSmoothCollisionSurface` C++ regression test. The shape
  is **not** registered with an Unreal BodySetup, not cooked, not a
  verified Chaos collision shape and not used in live gameplay.
- Tighten portable editor-candidate and source-art checks, including
  cross-platform floating-point tolerance, fail-closed geometry JSON,
  separate hash-linked receipts and Windows PowerShell syntax coverage.
