# Latebrake v0.3.0 — Garage and Tuning (Source Pre-release)

**Release format: SOURCE ONLY.** There is no verified playable Win64 executable, Android APK/AAB, Linux package or Unreal Engine game build.

## Added

- Three fictional starter vehicle tuning profiles: Arrow (free), Kestrel (600 earned credits) and Phantom (1,200 earned credits).
- Prototype silhouettes based only on existing engine primitives, not original finished car meshes.
- Optional garage unlocks and shared three-level Engine and Grip upgrades, paid from offline in-game race credits only.
- Bounded, deterministic C++20 garage economy and vehicle stat calculations.
- New Unreal SaveGame fields preserving unlocks, selection and upgrade levels with fallback for previous profiles.
- Vehicle performance multipliers applied to the starter rigid-body controller.
- Keyboard shortcuts and garage status readouts in the existing racing HUD.
- Portable garage tests for purchases, invalid input, price tiers, save restoration and overflow.

## What this does not verify

The GitHub Actions test matrix compiles the **engine-independent C++20 modules only**. Unreal Header Tool generation, Unreal gameplay class builds, in-editor driving, physics balancing, SaveGame serialization, garage UI layouts and actual Win64/Android packages are **not yet tested**.

No third-party commercial car art is bundled; the three vehicles are still geometric prototypes. There is no fully finished garage interface, multiplayer, packaged mobile controls or stable 1.0 quality certification.

See [garage technical design](../GARAGE.md), [engineering status](../STATUS.md), and [first playable build issue](https://github.com/sanskarIN/latebrake/issues/2).
