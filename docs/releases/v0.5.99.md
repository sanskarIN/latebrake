## Mainline changes verified at the publishing source SHA

- PRs #361–#364 strengthen real-AI closing and braking runway,
  frame-time rejection before verified gate traces and recovery, and
  three-or-more real road contacts for BOTH drafting cars.
- PRs #365–#366 reject ghost replay samples whose real motion is
  discontinuous even when neighboring sparse keys appear plausible.
- PR #368 rejects physical lateral sliding by either vehicle in
  the human-only 0.18-second drafting qualification window.
- PR #369 independently checks **relative world motion** against measured
  forward and lateral velocities, revoking boost after an unexplained
  in-lane jump, relocation or stale position.
- PR #370 requires a collision-query clear physical path between the
  actual player chassis and rival chassis. A blocking world object
  cancels drafting immediately; re-entry must earn a fresh confirmation.
  This is source-bound Unreal integration, not measured hardware QA.
- The actual optional drafting motor help stays at most +6%, and
  total nitro plus drafting extra motor-force stays within +40%.
  This source work does not grant checkpoint, lap, career, profile or
  reward authority. Independent normal force, braking and reverse
  constraints remain in effect.
