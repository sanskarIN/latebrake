## New engineering source since v0.5.70

Three additional player-facing analysis panels use actual run data
inside the already-bounded Results menu.

### Retained lap performance

The last two to eight genuinely timed and recordable completed laps
produce a measured average, median, population standard deviation and
signed newest-versus-recent-average pace. A faster-lap streak requires
strict consecutive adjacent timed laps without ties. If a long event
has more than eight laps, only the most recent eight are represented;
the earlier evicted timings are never reconstructed or guessed.
A single lap cannot show fake statistical spread.

### True per-gate best sectors

Results show the verified best positive split for each official
checkpoint in the completed run. The sum is a **theoretical mixed-lap
reference**, potentially combining different laps; it is NOT a newly
achieved lap time, leaderboard entry, career result or reward gate.
Invalid/penalty-only/untimed finishes do not expose these readings.

### Sampled chassis session report

The Results page reads the source's existing per-car driving samples,
showing approximate speed-integrated kilometers, measured peak speed,
brake presses, percentage of accepted sample time spent braking, and
high-lateral-slip sample share on expanded desktops. Missing or
nonfinite samples fail closed. Estimates can omit invalid/paused
frames and are **not** an odometer, official race clock or performance
rating. The compact screen suppresses optional secondary rows while
allowing all details through the existing UP/DOWN pager.

These changes are presentation-only. No vehicle dynamics, controls,
rival logic, lap awards, save format, checkpoint sequence, time fees,
progression credits or multiplayer/network features are changed.
