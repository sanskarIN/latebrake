## New gameplay source since v0.5.74

- Real GameMode `RaceStartLights` enforces a deterministic **3 → 2 → 1
  → GO** sequence for Quick Race, Time Attack and Career starts.
  Only a valid circuit, verified grid placement, current physical
  driver and unpaused/unfocused event consume the red countdown.
- `RaceProgress` receives **only post-GO elapsed time** on the exact
  frame crossing three seconds. Red frames cannot become lap records,
  future career credits, achieved sectors or an artificial head start.
- Both player driving and experimental rival control, genuine ordered
  checkpoint scoring and paid recovery/teleport are authorized by
  one shared GameMode green flag. Invalid/hitch frames (>0.5s), pause,
  OS focus loss and menu interruption do not consume the sequence.
- New accepted race restart resets lights and official elapsed time.
  Canvas HUD shows START LIGHTS 3/2/1 then short GO after the authentic
  clock, not via its own independent cosmetic timer.
- New strict C++20 regression compiles actual production
  `RaceProgress.cpp` to verify exact crossing-frame remainder,
  no free elapsed red seconds, invalid-frame pause, correct restart
  and GO banner expiration. Python contracts verify production Unreal
  GameMode, player pawn, rival, recovery, checkpoint and HUD wiring.

## Release source qualification

Publication requires independently successful immutable source-commit
checks on Ubuntu, Windows and macOS, all strict C++20/CTest, Unreal
source-binding Python tests, PowerShell synthetic candidate/provenance
rejection checks and GitHub Pages documentation integrity. The source
publisher refuses an advanced `main`, changed tag, missing warnings,
a mismatched published predecessor v0.5.74 or executable assets.
