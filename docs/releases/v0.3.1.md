# Latebrake v0.3.1 — Garage and HUD Reliability (Source Pre-release)

**Source-code preview ONLY.** This GitHub pre-release does not contain a validated playable game, tested Win64 EXE, Android APK/AAB or Linux executable.

## What changed

- Prevent negative/corrupt saved vehicle ownership masks from unlocking the garage for free; preserve owned valid positive bits.
- Centralize the next vehicle, next purchase and upgrade-price calculations in the portable garage model.
- Show actionable garage feedback and upgrade costs directly in the starter racing HUD.
- Adapt HUD spacing and displayed telemetry to compact viewports without dropping core race data.
- Protect racing best-time records from nonfinite/invalid values and prevent integer overflow in completed races.
- Add independent C++20 HudLayout and RecordValidation regression suites and extend GarageState tests.

## What was validated

The GitHub release pipeline must pass portable CMake/CTest on Windows, Ubuntu and macOS against the exact published source commit. These tests **do not compile Unreal Engine 5.8 C++ actor classes**, test visual UI layout in UE, or validate physical platform packages.

## Still missing for a playable or stable release

Licensed Unreal editor/UHT compilation, actual Win64/Android game packaging, original finished vehicle and world art, SaveGame migration tests in Unreal, gameplay/input/HUD/device QA. See [open qualification issue #2](https://github.com/sanskarIN/latebrake/issues/2).
