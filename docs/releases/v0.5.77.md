## New source since v0.5.76

### Player gameplay/telemetry

- A C++20 `VehicleGForceMeter` samples the genuine car's consecutive
  **world-space Chaos XY linear velocities** and projects acceleration
  onto the chassis heading. The optional expanded racing HUD displays
  smoothed signed forward/side G; a valid finished Results page displays
  advisory session peak braking and cornering estimates.
- It deliberately refuses malformed, interrupted, extremely short,
  long, implausibly fast or >6g delta samples. Teleports, restart, pause,
  physics invalidity and focus loss cannot bridge motion histories into
  phantom performance peaks. Only a genuinely held brake while moving
  forward can qualify a braking peak. No credits, race classification,
  saving, steering forces or leaderboard changes are involved.
- The earlier signed physical 0–5 km/h launch-speed telemetry is now
  interpolated **only between uninterrupted short valid samples**,
  with a conservative measured-time fallback for gaps. It is not
  human-reaction-time measurement.

### Private Windows owner playtesting

- `Build-Windows-Playtest.cmd` and real `Build-WindowsPlaytest.ps1`
  simplify a **local Unreal Engine 5.8 Editor/UHT/RunUAT candidate**
  build on an authorized Windows workstation. They do not download or
  fabricate a game executable and do not upload any game package.
- A real candidate can be re-launched through
  `Play-Windows-Candidate.cmd` or `Run-WindowsPlaytest.ps1`.
  This checks SHA256 candidate integrity and plausible cooked Win64
  structure before launching genuine `Latebrake.exe`, collects a
  separate Unreal log and private process receipt, and honestly labels
  actual gameplay as *unverified*. A valid exit code is not enough.
- Hardened parent-directory junction/symlink checks block diagnostic
  logs from escaping back into a fingerprinted game archive.
- A local, Python standard-library QA reviewer can create and evaluate
  **manual self-reported** braking, steering, checkpoints, physics,
  pause/focus, recovery, save and hardware observations linked to the
  actual candidate receipt, executable and manifest SHA256. Even nine
  reported passes never auto-certify the game.

## Source qualification before publication

All source tests are independently rerun at the **same immutable commit**
across Windows, Ubuntu and macOS. The pipeline also verifies Unreal-source
Python contracts (not UE/UHT), source/build provenance and fake-package
rejection policies on hosted Windows, and the rendered MkDocs website.
It checks predecessor v0.5.76 is a published asset-free source preview,
refuses moved `main` or retagging, and publishes **no compiled binaries**.
