# Latebrake v0.2.0 — experimental racing systems (source-only preview)

**Release type:** GitHub prerelease, SOURCE CODE ONLY.
**Playable status:** Not validated. No tested Windows EXE, Android APK/AAB or Linux game packages.

## New source functionality

- Two starter offline event modes: three-lap Circuit Race and one-lap Time Attack, using the same four gates.
- Keys `3` and `4` switch events and restart the race. Best race times are separated by event.
- First experimental AI rival follows a deterministic waypoint route on the circuit. No tested opponent ranking, overtaking or avoidance.
- Rivals cannot award player gate progress because overlap handling checks the actual local-player pawn.
- Race finish awards offline credits and a clean-run bonus using portable deterministic reward rules.
- Race HUD displays current event, accumulated credits, last race reward and racing statistics.
- C++20 tests for event definitions, waypoint steering, race ordering, timing and event rewards.

## What has been tested?

Only the **portable non-Unreal logic** using GitHub Actions compiler/CTest jobs across supported hosted runners. An Unreal Engine SDK/editor was unavailable, so **the game-specific C++ classes have not been compiled or playtested**, and Unreal runtime behavior and mobile controls remain unverified.

## What remains before a playable or stable game release?

A legal UE 5.8 workstation/editor build; original cookable project level and vehicle content; wheel/suspension improvement; robust AI race results; Win64 and Android packages and physical tests; saves, input, graphics, accessibility and release license audits.

Neither this source prerelease nor green CTest means the game runs on hardware. See [issue #2](https://github.com/sanskarIN/latebrake/issues/2), [status](../STATUS.md), and [test plan](../TESTING.md).
