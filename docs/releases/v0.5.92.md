## Changes since v0.5.91

- Preserve qualified four-corner spring lift independently of optional
  driving-policy failures, using one force submission per accepted frame.
- Qualify springs by real chassis attitude, avoiding wheel support on an
  inverted body; retain aerodynamic drag but remove unsupported tire
  rolling/shoulder resistance in flight.
- Measure advisory launch speed from signed horizontal motion so vertical
  landing velocity does not count as forward acceleration.
- Replace the global forward/nitro planar velocity snap with bounded
  opposing force. The separate reverse-gear safety cap remains.
- Bound opposing-throttle braking by pedal demand, surface/tire/garage/
  damage grip and accepted rear-axle support; include it in the existing
  same-frame cornering budget without stacking service/handbrake forces.
- Limit the combined base, nitro and drafting propulsion to the grip
  remaining after actual planned cornering force and the measured rear
  support ceiling. Preserve ordinary under-budget straight-line thrust.
- Damp static-road spring ray-length changes using the actual corner
  velocity and hit normal. Tangential uphill/downhill motion no longer
  creates false damping in the portable model; flat heave, compression,
  rebound and angular corner motion are retained. Initial-overlap rays
  cannot supply tangent-plane road support.
- Carry the main-line Android viewport-action epoch fix into the draft.
- Add strict C++20 regressions, actual Unreal-source binding checks and
  detailed engine/driving acceptance procedures for these changes.

## What the checks establish

The candidate has **184 standalone C++20 tests** and **659 Python source
checks**, plus documentation and PowerShell validation. The release
workflow reruns the complete candidate suite on its exact pinned commit
with Windows, Ubuntu and macOS portable jobs and verifies source-only
release labels and immutable identity before publication.

The numerical/reference tests include changing wheel support, axle grip,
boost/gear/lateral composition and independent static-plane derivative
fixtures. These are **not Unreal Engine 5.8 Editor/UHT/Game builds**, real
Chaos suspension measurements, installed Win64 playtests or Android QA.
The chassis remains a simplified rigid-body prototype with ray springs,
not a validated per-wheel tire/differential solver or finished racing game.
