## Changes since v0.5.1

- **Directional racing checkpoints:** Replace overlap-based sector credits with genuine ordered, forward plane crossings at each of four circuit gates. Sample 3D movement and check signed direction, minimum speed, interpolated lateral lane and vertical limits.
- **Low-FPS swept checkpoint acceptance:** Permit authentic forward frame-to-frame sweeps at up to 1,200 cm total travel even when samples straddle the former 600 cm sphere boundary; reject long discontinuities, wrong direction, missed lanes, invalid numbers and airborne shortcuts.
- **Teleport-proof progress:** Recover, race restart, invalid samples and pawn replacement reset checkpoint trajectory baselines. A short recovery across a gate cannot award a lap or sector.
- **Finish/save record reliability:** Reject unrecordable race/fastest-lap durations before awarding career medals, credits, completed-race counters or overwriting valid best times; sanitize records before serializing.
- **Career fairness:** Protect the garage from changes during an active career challenge; stage required-vehicle re-equipping on completed-race replay, persist it first and roll back when saving fails. Preserve recovery time-charge accuracy.
- **Rival race consistency:** Match rival route lap goals to the active career event and preserve that configuration on restart.
- **Android input cancellation:** Neutralize cached smoothed steering/throttle as well as touch ownership on viewport resizing/loss and player-controller loss, preventing lingering physics input.

## Source-only validation

The release workflow checks this exact immutable source revision with strict C++20 CMake/CTest on **Windows, Ubuntu and macOS**, PowerShell package-policy negative tests and parser validation, and Python editor automation stub/syntax checks. Genuine UE code, Unreal Header Tool, authored map packages, installed Win64/Android gameplay, hardware FPS performance, controls and distribution assets have **not** been tested by those workflows. Automated tests are not proof of a playable game.
