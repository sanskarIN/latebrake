## Source changes since v0.5.22

This source snapshot captures 8 additional unpublished development milestones, v0.5.23–v0.5.30, on the verified `main` source history:

- **Protected packaging provenance:** Reject dirty/untracked source before Editor and UAT stages; pin the source commit across long builds; snapshot project-owned circuit map SHA-256 before/after cooking; reject mismatching Windows/Android candidate identities. These are build-policy rules, **not** evidence of an actual cooked package.
- **Racing session integrity:** Deny player recovery while the circuit is incomplete, menu/world is paused, player physics is unusable, or race is finished; preserve the full five-second penalty for an authorized recovery.
- **Physical vehicle readiness:** Ensure the pawn has a finite, simulated, collision-bearing chassis before counting race time or scoring checkpoint gates; reset traces across broken physics intervals.
- **Mobile input safety:** Accept finger release events while paused, maintain independent held-finger ownership, and neutralize filtered throttle/steering after invalid coordinates, physical lift or movement off control pads.
- **Checkpoint continuity:** A sample with NaN or infinite velocity now invalidates the movement baseline. It cannot create a phantom forward crossing on the next frame; a fresh valid baseline and subsequent genuine crossing are required.
- **GitHub Pages website:** Public project documentation, feature explanations, build guide, source-only status, roadmap, and dedicated qualification instructions now publish at https://sanskarin.github.io/latebrake/.
