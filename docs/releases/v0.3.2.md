# Latebrake v0.3.2 — Control Safety & Garage Reliability

**Source-only pre-release candidate.** GitHub's automatic ZIP/tarball is source, **not** a playable or validated Windows/Android build.

## Added and fixed

- Input validation and normalization for keyboard/gamepad, autonomous driving and prototype two-finger touch.
- Gradual throttle transitions using a testable frame-step clamp; braking still takes effect immediately.
- Clearing held inputs when pausing/resuming or resetting the car, preventing input from being stuck.
- Nonfinite physics delta/velocity and touch-coordinate guards.
- Player-garage tuning cache, so credits and purchases do not trigger expensive per-frame handling updates.
- Visible in-game warning when local progress cannot be written to a SaveGame slot.
- More portable C++20 tests for invalid numbers, time-step overflow, touch positioning and revision-key validity.

## Verified and not verified

The release automation must compile and execute the **portable C++20 CMake test suite** on Windows, Ubuntu and macOS against the tagged revision, then mark this as a GitHub *pre-release*.

**No licensed Unreal 5.8 editor/UHT compilation, in-game driving or save testing has been carried out here.** This tag must not be described as a tested playable game. No Win64 executable, Android APK/AAB, Linux package, original production car models or final mobile controls are attached.

The remaining real-game qualification gates are tracked in [issue #2](https://github.com/sanskarIN/latebrake/issues/2). See [STATUS](../STATUS.md) and [TESTING](../TESTING.md).
