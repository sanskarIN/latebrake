# LateBrake v0.5.0 — Career & Championship Foundations

**GitHub classification: SOURCE-ONLY PRE-RELEASE.** This is **not** a
verified playable Windows/Android game. No UE 5.8 Editor/UHT/game-target
build or installed device gameplay test was performed. GitHub automatically
generated ZIP/tar archives are **source code**, not executables.

## Source changes

- Two new original championship series: Rookie Cup and Prologue Cup,
  three sequential rounds each, reusing the existing starter circuit.
- Six standalone replayable challenges: clock, clean driving, checkpoint
  precision, lap consistency, Kestrel-specific, and six-lap endurance.
- Deterministic bronze/silver/gold tier evaluation with strict player
  checkpoint/lap validation, points and per-series progress.
- One-time first-completion credits and once-only championship bonuses,
  medal improvement on replay, and preservation after career save/reload.
- SaveGame schema v2 with legacy race/garage migration, invalid progression
  sanitation, and future-schema write protection; option to display MPH.
- Unreal-facing career event selection and 1–6 lap race configuration;
  final player-only scoring integrated with garage earnings and SaveGame.
- Portable ten-screen menu navigation model and source-level Canvas overlay,
  keyboard/gamepad bindings and Android menu touch controls.
- Mobile stale-input cleanup on application lifecycle transitions, plus
  release builder preflight requiring a genuinely authored project .umap.
- Expanded strict C++20 CMake/CTest suites and release documentation.

## What test evidence means

The release workflow builds and tests the exact tagged source revision with
portable GCC/Clang/MSVC-compatible C++20 tests on Windows, Ubuntu and macOS.
It tests domain rules only, **not** Unreal gameplay classes or Android/Win64
binaries. The current repository lacks a verified cookable project-owned map,
Unreal Engine 5.8 installed CI runner, UHT/UBT compilation, driver/hardware
tests, and verified packages. Unreal runtime code remains **engine-unverified**.

## Required before playable binaries can be attached

1. Install/configure a licensed UE 5.8 engine and supported Windows/Android
   SDKs on an authorized workstation.
2. Resolve any editor/UHT and Unreal game-target compile failures.
3. Author/save a real project `.umap` via Unreal Editor and validate cook.
4. Execute the existing `scripts/Build-PreRelease.ps1` packaging helper,
   record build metadata, hashes, and run installed Win64/Android game tests.
5. Verify `scripts/Verify-ReleaseArtifacts.ps1` and evidence from actual
   tested devices. Upload **only** those genuine artifacts.
6. Keep [engine issue #2](https://github.com/sanskarIN/latebrake/issues/2)
   and [Android issue #13](https://github.com/sanskarIN/latebrake/issues/13)
   open until their requirements are genuinely complete.
