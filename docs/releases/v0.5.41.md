## Changes since v0.5.40

- **MAP AUTHORING RECEIPT:** Unreal Editor Python now rejects reported engine versions other than 5.8, and emits a schema-v1 success receipt including SHA256 of the **exact saved serialized** `/Game/Maps/LatebrakeCircuit` bytes, not merely the map name and length.
- **Version preflight:** Calling `New-StarterMap.ps1` directly also checks the installed Unreal Engine's `Build.version` and the project's engine association before launching the editor.
- **Fail-closed packaging handoff:** The Windows stage deletes prior receipts and refuses malformed/wrong-version/unexpected-map records, missing files, reparse-point paths, same-size modified map bytes, incorrect lengths or mismatched SHA256 before the existing Unreal header and pre-/post-UAT map-snapshot gates.
- **Source tests and transparency:** Regression tests cover valid stub authoring, bad engine versions and SHA256 correctness in Python, plus synthetic PowerShell fixtures for same-size tampering and corrupted receipts. The new `docs/MAP_AUTHORING_QA.md` describes the workflow and limitations.
