## New gameplay-source features since v0.5.60

This release groups merged source-only development into one independently
tested snapshot. Intermediate v0.5.61–v0.5.64 source milestones were not
separate GitHub binary or source releases.

- **Verified rival radar:** expanded HUD circuit map now shows a true live
  physics-ready rival marker, actual player heading, next official
  scoring gate and finite **direct planar separation** in metres.
- **Off-track return guidance:** route back to the original four paved
  circuit rectangles after a sustained off-track warning, with bounded
  nearest-road direction/distance advice.
- **Rival corner AI refinement:** inbound-to-gate corridor checks prevent
  corner anticipation from relying on radial proximity across wrong lanes.
- **Close-opponent warning:** sustained direct separation within 15m for
  0.6s displays an advisory on desktop/compact HUD, retained through
  20m hysteresis and reset on racing-state discontinuities.
- **New signed rival motion trend:** finite, real consecutive radar
  readings indicate **CLOSING** or **SEPARATING** after 0.4s of
  sustained >=2m/s direct distance change. Teleport-sized jumps,
  unavailable bodies, invalid frames, race interruptions and noisy
  low-speed movement do not fabricate warnings.
- **Unreal HUD compile-scope correction:** the results-screen branch no
  longer references a local Race variable before its C++ declaration.

All new trends/warnings are HUD-only advice. They do not predict contact,
rank racers, infer relative lap gaps, modify player/rival vehicle physics,
apply penalties, alter checkpoint validity, save data or career rewards.
