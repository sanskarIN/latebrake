## Source release workflow integrity

- **Pre-release validation:** New standard-library Python `SourceReleaseWorkflowPolicyTests.py` detects structural errors in modern source-only release workflows before they are merged, including duplicated jobs and incorrectly quoted CTest filters.
- **Pinned source parity:** Tests verify the three cross-platform source checkouts and actual release publisher use the same fixed 40-character commit SHA. A mismatched tag, notes path or predecessor release check fails.
- **Integrity regression fixtures:** Malformed CTest strings, duplicate release sections, source-revision drift, wrong tag, incorrect release note path and missing source-only warnings are explicitly rejected by negative tests.
- **Grounded outcome:** These source tests address a real GitHub Actions configuration failure discovered while publishing v0.5.32. They are **not** a complete YAML parser and do not replace actual GitHub Actions execution.
- **No gameplay changes:** Source-only v0.5.33 live same-sector target feedback and v0.5.32 current-lap potential remain intact. Neither is a verified running game.
