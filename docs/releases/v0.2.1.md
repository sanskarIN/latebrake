# Latebrake v0.2.1 — Rival Control & Racing Reliability

**Type:** source-only GitHub pre-release (not a playable game build).
**Status:** source candidate pending the final GitHub Actions C++ test matrix and release publication.

## Changes

- Portable rival waypoint route progress and approximate completed laps.
- Eight-second low-speed stuck detection with recoveries that preserve rival route state.
- Autonomous control planning before the base vehicle's physics input application.
- Near-waypoint braking to slow in advance of turns, and safe handling of invalid speed readings.
- On-screen approximate rival route-lap and recovery telemetry.
- Shared C++20 steering smoothing for keyboard, experimental touch and AI controls.
- More automated route and steering test cases, including numeric overflow checks.

## Testing boundary

Portable C++20 regression tests execute on GitHub Actions for Windows, Ubuntu and macOS. **No licensed UE 5.8 gameplay build, real vehicle/rival playtest, executable, APK or AAB has been produced or verified.**

There is no real competitive ranking, overtaking or sophisticated path planner. The AI waypoint lap display is an approximate route diagnostic, not an authoritative race result.

## Required before stable v1.0.0

Compile editor/Unreal targets, create original cookable maps/assets, test driving and race results, then package and verify Windows and Android builds on physical hardware. Follow [release qualification issue #2](https://github.com/sanskarIN/latebrake/issues/2).
