## New v0.5.60 gameplay-source expansion

The release groups source development after v0.5.46 into one tested
**source snapshot**. Intermediate v0.5.47–v0.5.59 numbers do not each
represent a separately published GitHub release.

### New player-facing systems

- **Measured driving session dashboard:** the real Chaos pawn now records
  run-local estimated kilometers, peak km/h, braking time, high-side-slip
  time and distinct BRAKE activations. Data is shown on expanded desktop
  HUD and reset on explicit race restart. It is advisory, not saved to
  player profile or used in career scoring.
- **Next-gate route advice:** shows direct-line meters and left/right/
  straight/turn-around guidance to the NEXT actual scoring checkpoint.
  It rejects off-road/malformed poses and hides when the race is not
  ready. Compact mobile display is restricted to near-gate approaches.
- **Rival corner anticipation:** independent, finite-checked C++20
  policy improves early braking before all four corner waypoints without
  changing steering calculations, lap awards, or recovery accounting.

### Source hardening merged since v0.5.46

- Full three-axis recovery pose and post-move readiness before fee.
- Speed-sensitive steering for both handling modes.
- Verified and rejected rival recovery telemetry.
- Rejected player restart-grid placements block time and motor force.
- Paid RECOVER uses the same authoritative restart readiness gate.
- Restart verification is bound to the actual weak Unreal pawn identity.
- Corner traction assist and sustained wrong-way HUD guidance.
- Expanded C++20 portability tests and Unreal-source binding assertions.
- Documentation and a reproducible authorized UE 5.8 candidate build path.
