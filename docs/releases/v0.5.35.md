## Changes since v0.5.34

- **FOCUS LOST, RACE SUSPENDED:** On OS deactivation or background, the Unreal car pawn clears analog and touch controls and asks the authoritative GameMode to pause.
- **Fail-closed competition:** The allocation-free, engine-neutral `AppFocusRaceGuard.h` holds a suspension latch independent of `UGameplayStatics::SetGamePaused` success. It prevents ghost racing time, ordered checkpoint credit, recovery penalties and autonomous rival route advancement while focus is lost.
- **No automatic foreground resume:** Returning to the foreground clears stale controls but does not resume competitive timing. Only an intentional PAUSE/resume, menu closure or accepted race restart reactivates it, including one-step explicit resume when an OS has already unpaused the world.
- **Checkpoint continuity:** An active focus-loss transition advances the race session epoch. Old approach/crossing samples cannot be bridged into a fresh checkpoint credit.
- **Clear HUD message:** The expanded and compact in-game HUD source both show `FOCUS LOST - RACE SUSPENDED` when the latch is active.
- **Regression suite:** Portable `AppFocusRaceGuardTests.cpp` links the actual `RaceProgress.cpp` and covers world-pause failure, checkpoint continuity, repeated OS interruption, already-paused foreground auto-resume, recoveries, rival readiness, explicit resumption and finished races. Python source checks verify the real Unreal binding callsites and HUD.

## Source-level verification and limitations

GitHub Actions builds/tests the **real portable C++20 core** on Ubuntu, macOS and Windows, validates Editor-only source contracts, documentation, and PowerShell packaging-policy fixtures. A second source-only pre-release gate retests the exact pinned candidate. These results are not proof of successful Unreal Engine 5.8 compilation, a cookable serialized `.umap`, real app deactivation event delivery, Win64/Android gameplay, or packaged executables.

The generated source archive is not an installer. The release deliberately has **zero compiled/executable assets**.
