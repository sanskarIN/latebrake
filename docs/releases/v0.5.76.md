## New source since v0.5.75

- A new engine-independent `LaunchSpeedMeter` provides a provisional,
  session-only **0–5 km/h forward acceleration estimate**. It is not
  a human-reaction-time metric, lap record, career result or reward.
- The genuine `ALatebrakeCarPawn` publishes signed longitudinal Chaos
  rigid-body velocity. The GameMode samples that value after the real
  `RaceStartLights` GO transition, using authoritative live elapsed
  racing time **minus charged recovery penalties**. Reverse driving
  cannot count as a forward launch.
- The first eligible post-GO physics sample must itself be below threshold;
  an already-moving first observation invalidates the estimate rather
  than allowing a late deceleration to produce a false grid launch.
  A below-threshold physical sample must precede a genuine observed
  forward crossing of 5 km/h within 30 seconds of the start. Invalid
  velocity/clock samples, nonmonotonic time, interrupted race and
  unqualified driving cannot create phantom estimates. Accepted
  restart clears the measurement; successful recovery invalidates an
  uncaptured attempt. Once measured, a result stays immutable for
  that run even after recovery.
- The optional expanded HUD briefly shows the approximate result;
  Results includes session-only launch feedback. No save schema,
  credit balance, career medals, world forces, checkpoint scoring or
  existing racing awards are changed.
- Strict C++20 portable boundary tests link production `RaceProgress.cpp`
  and genuine `RaceStartLights` behavior. Python source-binding tests
  check the GameMode, player pawn, HUD and safety boundaries.

## Source qualification and publication

The release workflow builds and runs the entire portable C++20
test suite independently on Windows, Ubuntu and macOS at one commit.
It also runs the Unreal-source Python contracts (NOT Unreal itself),
synthetic PowerShell packaging/provenance rejection fixtures and
MkDocs site verification. Publication refuses a moved `main`,
missing safety warnings, a different tag or a predecessor that is
not an asset-free source pre-release.
