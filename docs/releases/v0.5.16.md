# LateBrake v0.5.16 — Android Touch Ownership Consistency

**SOURCE-ONLY GitHub pre-release. This is NOT a playable game build.**
**No compiled Win64 EXE, Android APK/AAB or other installable game is included.**
GitHub source ZIP/tar.gz archives contain C++/Unreal project source, **not installers**.

## Source improvements since v0.5.15

- **Common trackable touch index range:** The new `UI/TouchFingerRange.h` defines the same 16-slot physical finger bound for `TouchPressTracker` and `TouchDriveState`.
- **Prevent untrackable drive input:** Direct use of the lower-level steering and pedal input state can no longer capture an index that the actual press tracker rejects.
- **Keep viewport interruption safe:** Even a stray positive move index cannot bypass global viewport invalidation; old throttle/steering inputs are canceled after an invalid layout.
- **Regression coverage:** Portable C++20 `TouchFingerRangeTests.cpp` and expanded `TouchDriveStateTests.cpp` cover upper/lower index boundaries, release, independent ownership and invalid layout cancellation; the actual race/session tests also remain in the full CMake suite.

## Source-only release gates

The special `v0.5.16` release pipeline will require the existing **v0.5.15 pre-release**, build and test all portable C++20 targets on **Windows, macOS, and Ubuntu**, explicitly demand the new touch-finger test target, and execute Windows PowerShell package-policy negatives and Unreal editor Python stub tests. Only the exact tested `main` commit may become the immutable source-only tag.

**This is NOT a playable game build.** Real Unreal Engine 5.8 compilation, authored and cooked map, genuine Win64/Android binaries, phone multitouch, focus changes and orientation playtests are **UNVERIFIED**. Tests in hosted source CI cannot close [Android issue #13](https://github.com/sanskarIN/latebrake/issues/13) or [checkpoint issue #31](https://github.com/sanskarIN/latebrake/issues/31).
