## Changes since v0.5.43

- **EXACT ENGINE BUILD:** The build pipeline now snapshots SHA256 of the exact installed `Engine/Build/Build.version` contents **before Editor compilation**, checks it after map authoring, carries the same fingerprint into UAT cooking, verifies it after UAT and requires it when recording candidate archive metadata.
- **Candidate manifest schema v2:** `unreal_engine_build_sha256` is now a required lowercase 64-character digest in `Latebrake-candidate-manifest.json`. A legacy schema-1 manifest, missing or malformed engine-build field cannot pass the new archive reviewer. Genuine binaries are still required separately.
- **Win64/Android release pairing:** Candidates must share their source commit, map SHA, Unreal version and **exact Build.version fingerprint**. The former version-only match could accept distinct UE 5.8 changelists/installations bearing the same broad version label.
- **Fail-closed synthetic QA:** A new `Test-EngineBuildSnapshot.ps1` validates installed 5.8 metadata against the pinned digest; disposable PowerShell tests reject tampered same-size changelist JSON, unsupported engine version, missing/uppercase/truncated hashes and cross-platform UE-build divergence. Python source bindings check actual script handoffs.
- **Build documentation:** Explains the schema-2 migration and how to create a fresh pair of candidates with the same licensed engine.

## Source verification and limitations

Implementation [PR #118](https://github.com/sanskarIN/latebrake/pull/118) passed Windows/macOS/Ubuntu strict C++20, Python source-contract tests, Windows synthetic PowerShell packaging/engine fixtures and documentation CI. It merged at immutable tested source commit `5cf98c325048afd74214867bf1964228e0053e93`.

The independent publisher pins that exact code revision and reruns those checks before publishing; it checks the prior published asset-free v0.5.43 release and refuses modifying existing tags or attaching built packages.

**A Build.version SHA256 is not cryptographic authentication of UnrealEditor.exe, RunUAT.bat or the complete Epic SDK.** Equal engine metadata does not demonstrate that any licensed editor executed, that actual UHT/C++ compiled, or that physics, input, release packaging or device QA passed.

**No authentic cooked project map, compiled Win64 executable, Android APK/AAB, installed gameplay or verified target-hardware qualification has been produced here.**
