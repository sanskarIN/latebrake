# Latebrake v0.4.1 — Android Touch UX (Source-only Pre-release)

**Source-only Unreal Engine development pre-release. NOT an installed/verified
playable Android or desktop game. No Windows EXE, APK, AAB or Linux executable
is included.**

## What's new in source

- Shared portable C++20 layout drives both on-screen Android control graphics
  and touch input hit testing.
- Six responsive pads: STEER, GAS, BRAKE, PAUSE, RESTART, RECOVER.
- Two independent held fingers can steer and accelerate/brake; pressing
  elsewhere cannot activate pedals. Moving a pedal finger into the neutral
  gap releases both throttle and brake.
- Mobile pause/resume touch binding and restart-unpause path.
- Cleaner compact HUD and pressed-state tinting for steering/pedals.
- Standalone C++20 tests for geometry, screen sizes, touch hit testing,
  steering clamping, NaN/Infinity rejection and safe action separation.

## Verification claim — narrowly scoped

A local GCC 14 smoke test of the portable touch geometry compiled and passed.
The tagged source publication must be gated on Windows, Ubuntu and macOS
CMake/CTest runs of the complete portable test suite, executed against the
same commit that is tagged. The CI gate does **not** compile any Unreal
`UCLASS`, `UFUNCTION` or `BindTouch` code.

## Required before playable/stable release

- Authorized Unreal Engine 5.8 editor/UHT and game-target compilation.
- Landscape/portrait Android device input/render testing, including pause
  routing, focus-loss/cancel recovery, split-finger gestures and visibility.
- A real cookable map, sound/vehicle quality review, performance measurements
  and signed, installed Win64/Android builds with tested gameplay.
- Full compliance and release evidence from [issue #2](https://github.com/sanskarIN/latebrake/issues/2).
