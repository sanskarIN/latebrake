## What's changed since the main source-only milestone

The previously downloadable **LateBrake V5 Controller Edition** was
a separate Win32/GDI **2D** experiment. User feedback shows its pixel-art
menu, flat top-down car and simple courses are not the desired realistic
racing experience. This candidate does not reskin or reissue that 2D build.

Instead, the **actual Unreal Engine 5.8 C++** starter circuit receives:

- Eight white visual road-edge stripes on the actual straight collision
  slabs, plus forty-eight narrow dark braking-zone rubber segments across
  the four genuine directional checkpoint approaches.
- Complete rectangle-footprint validation against the four existing
  physical asphalt collision blocks. Invalid/nonfinite geometry, off-road
  footprints, floating slabs and hidden/buried marks are rejected.
- One optional holder with **two instanced-mesh batches**, collision,
  overlap events, shadowing and navigation disabled. Incomplete
  instantiation destroys the cosmetic holder; the nine race-physics
  collision blocks, four checkpoints and saved progression remain intact.
- A **genuine-editor-only** original material authoring script producing
  a project-owned, parameterized PBR parent in real Unreal 5.8.
  Runtime C++ prefers this authored material for roads, walls, scenery
  and new surface details when installed, falling back to existing
  engine primitives when missing. A SHA256-linked source-side receipt
  checks saved asset identity; no binary `.uasset` is fabricated or
  included in this source candidate.
- Portable strict C++20 geometry tests, Python Unreal source-binding tests,
  documentation, and an explicit manual Windows/engine QA plan.

## What this is NOT

It is NOT the real game version of the pixel-art menu screenshot.
It does NOT contain a compiled Windows Unreal executable or installer,
cooked `.umap`, authored and inspected material `.uasset`, photorealistic
textures, real vehicle body meshes, a redesigned curved physical circuit,
UE5.8/UHT Editor compilation, measured installed-device FPS,
or verified human gameplay. Exact-source automated tests check code
contracts only; do not convert their passing status into a playable badge.

## Pre-release acceptance gates (not yet satisfied)

1. Full portable C++20, Python, PowerShell and docs CI **green at exact
   tagged SHA** on Windows, Ubuntu and macOS.
2. Authorized licensed UE 5.8 Editor/UHT compile and real material
   generation / shader compilation, real map cook and Win64 packaging.
3. Windows desktop manual graphical inspection, track boundaries,
   rear-wheel physics/contact, checkpoints, camera and controls at
   multiple frame rates.
4. A GitHub release with explicit **SOURCE ONLY / NOT PLAYABLE**
   designation and **no** fake executable assets, only when intentionally
   publishing this experimental source snapshot.

## Project focus after this source preview

The next large game-quality work is genuine drivable **curved track
geometry**, textured asphalt/shoulders with proper collision agreement,
independently authored realistic **3D car meshes and interiors**, refined
cameras, lighting and audio. That work must be validated in installed
Unreal builds before another Windows EXE is offered as the 3D preview.
