# Latebrake v0.1.1 — second pre-release development plan

**Status:** In progress; no tag or release published. Developed independently on `feat/v0.1.1-race-stability` while v0.1.0 still awaits verified UE platform packaging.

## Source changes completed on development branch

- Track current lap duration, last lap duration, fastest lap within a race and last sector split in the core portable race state machine.
- Protect clock accumulation against NaN, infinite deltas and floating-point overflow.
- Extend the in-game racing HUD with lap/sector telemetry.
- Persist fastest completed lap to the SaveGame profile, defaulting a new field for old profiles.
- Reject circuit checkpoint overlap when the starter car enters the gate going backwards or without meaningful directional velocity.
- Add more C++20 regression tests for lap/sector calculations, invalid gate directions and timing overflow.

## Deferred

No multiplayer, AI opponents, licensed commercial car meshes, mobile tilt input or stable-quality wheel physics are claimed for v0.1.1.
