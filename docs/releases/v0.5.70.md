# LateBrake v0.5.70 — Safe HUD and Timed Lap Review

**SOURCE-ONLY GitHub pre-release. This is NOT a playable game build.**
**No compiled Win64 EXE, Android APK/AAB, or installed playable game is included.**
GitHub-generated source ZIP/tar.gz archives are **not installers**.
This pre-release includes **zero executable binaries** and no cookable game asset.

## Source changes since v0.5.65

- **v0.5.66 — vertically safe racing HUD:** critical LAP/GATE and TIME
  rows appear first, telemetry is bounded above Android touch controls,
  optional messages yield to essential pause/save/finish alerts.
- **v0.5.67 — measured horizontal text clipping:** actual Unreal font
  measurements and mobile touch geometry prevent overlapping race/menu
  text without fabricating fixed-width font assumptions.
- **v0.5.68 — bounded menu layout:** Results/Career/Garage details fit above
  physical steering pads with independent SAVE FAILED and overflow notices.
- **v0.5.69 — accessible detail pagination:** preserve ALL generated
  Results/Career/Garage detail rows with UP/DOWN keyboard/touch navigation;
  menu category navigation remains separate.
- **v0.5.70 — genuine recent timed-lap review:** the Results page renders
  up to eight real completed timed laps, newest first, showing physical
  lap ID, seconds and difference from within-run best. Expanded desktop
  view also shows the signed change from the previous retained timed lap.
  Incomplete, penalty-only and unrecordable finishes never receive a
  legitimate lap summary. History is bounded and resets with the race.

All changes remain offline, source-level and local. They do not modify
vehicle physics, player progression, SaveGame schema, official times,
career credits, checkpoint awards, original art licensing or AI behavior.

## Independent source qualification

The release publisher builds and tests the **exact main-branch SHA
being tagged**, refusing to overwrite any existing tag or to publish
when main advances during qualification. All release jobs must pass:

- Three-OS strict C++20 compile and complete `ctest` suite, including
  production-linked `RecentLapReview`, `HudVerticalPlan`,
  `HudTextBounds`, `HudMenuVerticalPlan` and `MenuDetailPager`.
- Unreal source-only Python syntax and binding contracts. These do not
  invoke Unreal Header Tool or compile Unreal game/editor classes.
- PowerShell source and synthetic packaging rejection policies, not
  actual installers or hardware results.
- Pinned documentation build and generated-link verification.

## What still blocks a playable or stable release?

No authorized Unreal Engine 5.8 Editor/UHT build, genuine authored and
cooked circuit map, packaged Win64/Android game target, installed device
test, Android touch interruption check, handling/physics measurement,
full UI font/DPI QA or sourced playable binaries has been verified.

Before any playable release, compile the actual engine targets, author
the real original circuit, build and fingerprint authentic packages,
perform physical Windows/Android runs, and attach verifiable QA
evidence to [Android qualification #13](https://github.com/sanskarIN/latebrake/issues/13).

The GitHub release must contain **zero executable binaries**, and the
source archives are not installers. Authored LateBrake source is licensed
BSD-3-Clause; Epic content and Unreal Engine use separate Epic terms.
