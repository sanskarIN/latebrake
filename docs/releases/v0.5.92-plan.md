# v0.5.92 source pre-release and suspension qualification plan

**Source snapshot prepared for publication; no playable build is qualified.**
The experimental source-only milestone may be published from the tested,
unmerged PR before engine qualification, as with v0.5.91. Publication must
not merge the physics, claim an installer, or rewrite an older immutable tag.

## Scope

Finish the existing [suspension PR #295](https://github.com/sanskarIN/latebrake/pull/295)
before moving to another gameplay feature. The candidate consolidates
four-corner spring/anti-roll support, real axle-load grip, reattachment,
bounded opposing-throttle braking, shared motor/cornering grip, smooth
overspeed force and static-slope ray-length damping.

## Sequence and acceptance

| Stage | Required evidence | Current status |
| --- | --- | --- |

The engine procedure is [trusted PR validation](../UNREAL_DRAFT_PR_VALIDATION.md):
dispatch from **main**, PR number **295**, the **current full 40-character
head SHA**, and **Editor** first. Only after Editor/UHT passes, repeat with
**Win64**, then perform the installed [suspension QA](../SPRUNG_CHASSIS_QA.md).
An authorized isolated Windows runner with licensed UE5.8 is required.

## Release-note requirements

- Describe the actual simplified rigid-body suspension and known limitations.
- Distinguish portable/source CI from real engine builds and installed driving.
- Include exact source and engine identity, artifact hashes, supported
  platform and the hardware/frame-rate results actually observed.
- List remaining handling, art, audio and performance limitations plainly.
- Keep the version marked pre-release; passing these physics checks alone
  does not establish a complete production racing game or stable release.

Do not merge this physics candidate or mark a game playable merely because
portable CI passes. The broader playable-game gate remains
[issue #148](https://github.com/sanskarIN/latebrake/issues/148).
