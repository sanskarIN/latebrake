# Latebrake v0.1.0 — candidate release notes (NOT PUBLISHED)

**Release type:** First pre-release, pending real playable builds and test evidence.

No GitHub release or official v0.1.0 version tag has been published. The current original game code is a developer preview; portable C++20 CI alone does not certify an Unreal game build.

## Candidate player experience

- Starter rigid-body vehicle with keyboard/gamepad and experimental touch input.
- Procedural circuit with four ordered gates, three-lap timer, and restart.
- On-screen racing telemetry and local best-race records.
- Arcade and simulation-inspired controls, pause, recovery and camera distance.

## Required release checklist

- [ ] Compile Unreal Engine 5.8 editor game modules and run PIE.
- [ ] Produce and test an original, cookable project-owned map and packages.
- [ ] Build and play a Win64 archive on real Windows hardware.
- [ ] Build and play an Android APK on supported physical Android hardware.
- [ ] Test Android touch, lifecycle, save locations and UI readability.
- [ ] Execute input, race-order, restart, pause, persistence and crash regressions.
- [ ] Attach **real** downloadable Win64 package and Android test APK; record SHA-256 hashes.
- [ ] Report tested GPUs/devices, FPS data only when measured, and known failures.
- [ ] Review Epic redistribution license restrictions and included asset notices.
- [ ] Publish `v0.1.0` as a pre-release only after all required gates pass.

Do not upload empty ZIPs, an automated unit-test binary masquerading as a game, or a non-UE substitute as a playable release.
