# Finished sector history panel

Ordinary race, Time Attack and career Results can display a wide desktop
inspection panel in the existing protected right-hand navigation lane.
The experimental fleet keeps its replay in that lane. Compact and
Android layouts retain the text review. No new driving input is bound.

Each gate tab shows up to four recent actual accepted laps at once.
Older/newer navigation covers the retained 32-sector window. A shared
scale per gate includes fees; active time and fee portions are distinct,
with a separate gold coverage strip. The best marker is the shortest
qualified rolling sector in retained history, not a record or a claim
about unretained history. Untimed rows remain selectable and empty.
The selected row shows its actual qualification and sampled speed.

Mouse admission uses the same presented panel geometry and the actual
finished attempt revision. Disabled/empty cells do not trigger a race
restart or garage transaction. Resize, close and changed race revision
invalidate the old presentation. Native QA must test legibility, actual
font measurements, resize, all tabs, history wrapping, fees, missing
samples and normal menu navigation. This is source-level implementation,
not a claim of installed Unreal UI qualification.
