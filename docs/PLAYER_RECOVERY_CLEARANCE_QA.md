# Player recovery clearance and feedback

Paid RECOVER retains the original next-gate landing and five-second
transaction. A valid solo scene admits the original target; in a rival
event the actual opponent snapshot must clear the existing padded swept
footprint. Missing or unexpected rival state, occupied landing and
invalid geometry block the engine callback. No extra fee is charged on
a blocked or unverified attempt. A short HUD notice distinguishes
traffic, landing, clock, placement and success outcomes, using the
race clock and resetting with the attempt. It never initiates recovery.

Native acceptance: attempt RECOVER with the rival occupying or crossing
each landing, confirm no move/fee, clear the landing and retry, confirm
a verified move and exactly one five-second charge. Test Time Attack,
pause, restart, controller/touch recovery and compact HUD. A source
check or portable test is not Unreal UHT, cooked map or installed QA.
