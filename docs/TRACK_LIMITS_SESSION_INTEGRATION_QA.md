# Original circuit track limits integration

Integrates the existing projected-wheel steward from prior research
into the actual GameMode after a successful official clock advance.
A real clock/driver/teleport/session interruption suspends exposure.
The draft adopts the existing 0.6s warning, 1.5s strike, 0.5s rejoin
and five-second fee per third accepted violation. Existing records
created before this rule are not proof of comparable clean driving.
The HUD shows actual track/recovery fee attribution only when counts
and authoritative totals reconcile. It never adds time itself.
The previous wheel-overlap model is conservative visual geometry,
not real tire contact or a future circuit policy.

Native qualification must test 30/60/120 FPS, all four pavement edges,
grass/stationary/reverse, pause/restart/recovery, failed fee, real
checkpoint ordering, ghost invalidation after a fee, and results.
This source work is not licensed engine compilation, cooking or
installed game acceptance. Keep draft until those are verified.
