# Contextual Settings

Browse selects one of the three display settings; Select changes it.
The existing N / controller D-pad-right / mobile BROWSE input now
belongs to the Settings page instead of changing the pending career.
Enter / controller Y / mobile SELECT activate the current option.
F2 and F3 remain direct desktop shortcuts.

Speed units still use the existing profile save transaction and rollback.
HUD detail is session-only; lighting is the existing guarded visual
preview with actual runtime Sun/Sky components. Neither is persisted.

Desktop views have optional direct setting cards in the protected lane
below the navigation dock. Compact and touch views use the text cursor
and existing controls. A card needs complete actual-font captions and a
fresh presentation snapshot; stale or disabled hits cannot mutate settings.

Native QA: test keyboard, mouse, controller, touch, focus loss, resizing,
missing light components, save failure and future-schema read-only.
Verify Browse does not change a pending career event, and returning to
Settings selects speed units. Portable tests are not a native UI pass.
